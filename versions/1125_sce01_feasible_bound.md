## 修改内容

- 新增 `docs/simulator/sce01_无脚本可达性与最优flow分析.md`：
  对 sce01（无脚本、零事件的静态场景）给出**可证明的达标上界**与最优 flow 摆法。
  - 接入段负载与路由无关（每 UAV 仅一条可用接入链路 + 路径是简单路径）→
    凡接入方向超容的 test 业务物理不可达，**上界 = 5/10**（TSV0002/0005/0006/0007/0008 全卡 UAV0001）。
  - 三方案对比：生成器基线 3/10、当前规划器 5/10、600 次重启搜索最优 5/10（命中上界）。
  - 达标集合稳定但具体路径多解（搜索与规划器对 TSV0001/TSV0010 走法不同），
    说明"改路 ≠ 变好"，正是闭环 Δmin 闸门要拦的。
  - 明确标注口径：本文"达标"= 自身方向利用率 ≤100%（容量维度上界），
    不含排队时延/抖动/丢包对实测 `qosMeet` 的影响；实测达标数**待核对**。
- 新增 `scripts/feasible_bound.py`：输入场景 JSON 目录，输出接入段上界、
  `paths[0]` 基线/当前规划器/随机搜索三方案达标数与 flow 摆法。
  换场景直接换目录；sce01 约 9s（600 次重启），sce05 建议 `--restarts 150`。
