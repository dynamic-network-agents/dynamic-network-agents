# 实验记录模板

> 用途：记录一次静态实验定义。第一阶段从仿真场景文件自动导入并生成本记录；人工可补充实验目的、观察重点和备注。\
> 注意：本模板描述实验输入，不等同于一次已经启动的仿真运行。

-   [ ] 拓扑文件存在且 JSON 解析成功

-   [ ] 链路类型配置存在且已记录版本/哈希
-   [ ] 节点、链路、业务和事件统计完成

-   [ ] manifest_hash 已生成
