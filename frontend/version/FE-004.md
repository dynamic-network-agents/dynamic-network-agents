## 已确认决策

- 运行时校验选用 **Zod**（4.6.7）。
- 类型范围选 **首轮最小集**（§14 八类域对象 + 支撑子对象）；Agent/Policy/MetricPoint/ResourceAllocation/Experiment 等二轮类型延后到 FE-006 及之后。
- 目录新增 `src/schemas/`（Zod）与 `src/adapters/`（DTO→ViewModel）。

## 改动点

- 新增 `src/types/enums.ts`：§4 全部首轮枚举（`as const` + 联合类型）+ `coerceEnum` / `coerceEnumInsensitive`；未知枚举值返回 `undefined`，由适配器在必填字段 `?? 兜底`、可选字段丢弃。兜底值策略集中注释于文件头。
- 新增 `src/types/domain/`：`NetworkNode`(+Position/Mobility/NodeResources)、`NetworkLink`(+LinkParams)、`BusinessFlow`(+QosRequirement/QosMeasurement/QosViolation)、`Scenario`/`ScenarioEvent`、`SimulationRun`/`TopologySnapshot`(+TopologySummary)、`RealtimeEvent`(信封 + 首轮 data 联合 `RealtimeEventDataMap`)。
- 新增 `src/schemas/`：服务端 DTO 的 Zod schema（`node/link/flow/scenario/simulation/realtime`）+ `contest.ts` 赛题导入 schema；`.passthrough()` 向前兼容未知字段，ber/丢包率/可靠性等 0–1 越界即校验失败。
- 新增 `src/adapters/`：DTO → ViewModel 映射（枚举兜底、单位透传、缺失值处理）；`contest.ts` 实现赛题导入兼容——`bandwitdhBps`→`bandwidthBps`、`status` 小写归一、`linkType` 透传、`time`/`tsUs` 以 `tsUs` 为权威、默认 `linkPlane=DATA`/`direction=BIDIRECTIONAL`（可覆盖）。
- 更新 `src/types/index.ts`（由占位改为导出 enums + domain）。

## 功能描述

建立「外部数据 → Zod 校验 → 适配器 → ViewModel」分层；页面只消费 `types/domain/` 稳定 ViewModel，不散落硬编码 DTO 映射。控制/数据链路按独立 `linkId` + `linkPlane` 表达，不根据节点对推导；赛题旧字段仅在导入适配层兼容，不污染内部模型。
