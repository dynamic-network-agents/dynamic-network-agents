# FE-005 API 客户端与错误处理

- **日期**：2026-11-07
- **任务**：FE-005 API 客户端与错误处理（M0 工程基础 / P0，依赖接口规范 v1.0、FE-004）

## 已确认决策

- 领域 API 模块首轮覆盖 7 个域：dashboard / scenarios / simulations / topology / flows / qos / resources。
- Zod 校验与 DTO→ViewModel 适配**延后到 store 层（FE-006）接线**；API 函数返回服务端 DTO 类型（`z.infer`）。
- HTTP 传输选 **axios 1.21.0**、Mock 基础 **msw 3.0.4**（本次仅用于集成测试，MSW 生命周期在 FE-007 接入）。

## 改动点

- 新增 `src/api/types.ts`：传输层类型 `ApiResponse<T>` / `Page<T>` / `FieldError` / `ApiErrorBody` / `PaginationParams`；语义待确认的聚合 DTO 别名（`DashboardSummaryDto`/`QosFlowDetailDto`/`FlowRouteDto`/`NodeNeighborsDto`/`NodeRoutesDto`/`SimulationCapabilitiesDto` 等）以 `Record<string, unknown>`/`unknown` 兜底并标注「待与官方确认」。
- 新增 `src/api/errors.ts`：`ApiError`（`status`/`code`/`requestId`/`details`/`fieldErrors`/`cause`）+ 状态码→业务码/文案映射 + `fromHttpError`（提取 `details.fieldErrors ?? details.errors`）+ 分类守卫（`isValidationError`/`isConflictError`/`isNotFoundError`/`isAuthError`/`isServerError`/`isNetworkError`/`isTimeoutError`/`isCancelledError`/`getFieldErrors`）。
- 新增 `src/api/client.ts`：axios 单例（`getApiClient`，baseURL 取自 `getEnvConfig().apiBaseUrl`）、响应拦截器解包 `data`、`toApiError` 归一化（HTTP→业务码、`ERR_CANCELED`→`REQUEST_CANCELLED`、`ECONNABORTED`/timeout→`TIMEOUT`、无响应→`NETWORK_ERROR`、非 axios→`UNKNOWN_ERROR`）；`request<T>` 支持 `AbortSignal`/超时/`Idempotency-Key`/`If-Match`。
- 新增 `src/api/query.ts`：`serializeQueryParams`（undefined/null/非标量丢弃、数组逗号拼接）。
- 新增 `src/schemas/api.ts`：`scenarioValidateResultDtoSchema` / `eventInjectionResultDtoSchema` / `qosSummaryDtoSchema`（含 `qosViolationDtoSchema`，从 flow.ts 导出）。
- 新增 7 个领域 API 模块（`dashboard/scenarios/simulations/topology/flows/qos/resources`），路径对齐接口规范 §7.6–§7.9；写操作携带 `Idempotency-Key`（POST）、`If-Match`/`expectedVersion` 乐观锁（场景 PUT）。
- 新增测试工具 `src/test/server.ts`（MSW `setupServer` + `apiOk`/`apiErr` 封包辅助）；`src/test/setup.ts` 增加 `typeof window !== 'undefined'` 守卫以兼容 node 环境测试。
- 新增测试：`errors.test.ts`（12）/ `query.test.ts`（5）/ `client.test.ts`（8）/ `client.integration.test.ts`（6，node 环境）/ `api-modules.integration.test.ts`（4，node 环境）/ `schemas.test.ts` 增补 3 组 schema 用例。
- 更新 `src/api/index.ts`（barrel 汇总导出）。

## 功能描述

建立统一 HTTP 传输层：axios 单例 + 响应解包 + 错误归一为 `ApiError`，各业务 API 模块返回 DTO 类型；Zod 校验与适配由 store 层（FE-006）负责。解决 MSW 与 jsdom 下 AbortSignal 类不一致问题（node 环境跑 MSW 集成测试）。
