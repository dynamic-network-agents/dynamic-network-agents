# FE-007 Mock REST 与 WebSocket

- **日期**：2026-11-08
- **任务**：FE-007 Mock REST 与 WebSocket（M0 工程基础 / P0，依赖 FE-004 类型与适配、FE-005 API 客户端、FE-006 Store）

## 已确认决策

- **真实 WebSocket 通道仅留接口 + Mock，真实实现留空**：`RealtimeProvider` 接口 + `MockRealtimeProvider`（内存桥接）+ `NativeRealtimeProvider`（`subscribe()` 抛「真实通道尚未就绪」的明确提示）。§8.1 鉴权、§8.4 心跳待与官方确认后补真实实现。
- **确定性显式推进 `advance(ms)`**：Mock 不依赖墙钟定时器，仿真时间由 REST 写操作（`step`/`start`/`injectEvent`）显式推进；同一 seed + 相同操作序列结果可复现。
- **REST 与 WebSocket 共享单一 `MockWorld`**：MSW REST handlers 与 `MockRealtimeProvider` 读写同一份内存运行态，保证写操作推进状态并产生实时事件、后续 GET 查询反映相同状态。
- 引入 **msw 3.0.4**（`msw/browser` 浏览器 worker + `msw/node` 测试 server）。

## 功能描述

无真实后端时，前端用同一套内存运行态数据驱动 REST 与 WebSocket：MSW 拦截 REST 请求读写 `MockWorld`，`MockRealtimeProvider` 桥接其事件流；仿真时间确定性显式推进，切换 run 不串数据，同一 seed 复现同一结果。顶栏「Mock 模式」标记当前数据来源。真实 WebSocket 通道留接口空实现，待 §8.1/§8.4 确认后补齐。
