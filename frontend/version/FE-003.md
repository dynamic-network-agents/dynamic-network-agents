# FE-003 全局布局与路由

- **日期**：2026-11-07
- **任务**：FE-003 全局布局与路由（M0 工程基础 / P0，依赖 FE-001、FE-002）

## 已确认决策

- 引入 Ant Design **v5**（5.29.3）+ @ant-design/icons v5；CSS-in-JS，无需全局样式导入；`ConfigProvider locale={zhCN}` 汉化。
- 路由使用 React Router **v7**（`react-router` 包，非 `react-router-dom`）。
- 侧边栏（Sider）采用**深色主题**。

## 改动点

- 新增路由元信息单一来源 `src/app/pageMeta.tsx`：7 个一级页面的 `path / title / description / icon`，并提供 `getPageMeta` / `matchRoute` 等查询。
- 新增 `src/app/routes.tsx`（`routeConfig` 由 `pageMeta` 派生，页面 `React.lazy` 懒加载）+ `src/app/router.tsx`（`createBrowserRouter`）。
- 新增 `src/app/providers.tsx`（`ConfigProvider` + 汉化 locale）；改写 `src/app/App.tsx` 挂 `RouterProvider`。
- 新增布局组件 `src/components/layout/`：`AppLayout`（深色可折叠 Sider + Header + Content + 面包屑 + 懒加载 Suspense）、`SideNav`（菜单由 `pageMeta` 生成）、`TopBar`、`AppBreadcrumb`。
- 新增通用组件 `src/components/common/`：`PageHeader`、`PagePlaceholder`、`PageLoading`（懒加载回退）。
- 新增 7 个占位页面 `src/pages/{dashboard,topology,scenario,simulation,agents,resources,experiments}/index.tsx` 与 `not-found`（AntD `Result` 404 + 回到首页 / 返回上一页）。
- 新增测试工具 `src/test/renderWithRouter.tsx`：测试用**声明式 `MemoryRouter` + `Routes`** 复用同一 `routeConfig`，规避 React Router v7 数据路由在 jsdom 下 `new Request(url, { signal })` 触发 Node/undici 与 jsdom `AbortSignal` 类不一致的报错。
- 补强 `src/test/setup.ts`：为 AntD v5 补齐 `window.matchMedia` / `ResizeObserver` mock。
- 新增路由与布局测试：`src/app/pageMeta.test.ts`、`src/components/layout/AppLayout.test.tsx`（含逐路由渲染、菜单高亮、点击跳转、侧栏折叠、404 兜底与两种返回）。

## 功能描述

建立全局布局（深色侧边栏 + 顶栏 + 内容区 + 面包屑）与一级路由骨架；菜单、面包屑、页面标题、路由配置全部由 `pageMeta` 单一来源派生，杜绝多处重复定义导致的漂移。页面按需懒加载。当前页面均为占位（PagePlaceholder），业务内容随 FE-004+ 填充。
