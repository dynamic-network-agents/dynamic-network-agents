# FE-002 质量工具与测试框架

- **日期**：2026-11-07
- **任务**：FE-002 质量工具与测试框架（M0 工程基础 / P0，依赖 FE-001）

## 改动点

- 新增 Prettier 配置（`.prettierrc.json` / `.prettierignore`）与 `eslint-config-prettier`，消除 ESLint/Prettier 规则冲突
- 新增覆盖率（`@vitest/coverage-v8`，与 vitest 2.x 版本对齐）及 80% 阈值（statements/branches/functions/lines）
- 强化测试初始化 `src/test/setup.ts`：用例后自动 `cleanup` + 恢复 spy，保证隔离
- 新增公共测试工具 `renderWithProviders` 与测试数据工厂 `createFactory`（`src/test/`）
- 新增示例纯函数 `src/utils/format.ts`（仿真时间 / 百分比格式化）及测试
- 新增示例交互组件 `src/components/CopyButton.tsx`（复制到剪贴板）及渲染 + 交互测试
- 锁定 `@testing-library/jest-dom@6.9.1`（避开 6.10.0 的 Node≥22 破坏性变更）
- 新增 `pnpm format` / `format:check` / `coverage` 脚本；CI 增加格式检查与带阈值的覆盖率步骤

## 功能描述

补齐质量工具与测试框架，统一 `lint / typecheck / test / coverage / build / format` 命令可执行；PR 自动执行格式检查与覆盖率门槛；测试失败使 CI 失败并输出定位信息；提供纯函数与 React 组件两类示例测试，覆盖率 100%。
