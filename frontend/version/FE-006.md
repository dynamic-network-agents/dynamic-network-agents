# FE-006 Zustand 状态管理骨架

- **日期**：2026-11-07
- **任务**：FE-006 Zustand 状态管理骨架（M0 工程基础 / P0，依赖 FE-004 类型与适配、FE-005 API 客户端）

## 已确认决策

- 首轮建 5 个 store：`appStore` + `uiStore` + `simulationStore` + `topologyStore` + `scenarioStore`；Agent/Resource/Metric 三域 store 待其二轮类型补齐后再建。
- 异步状态机抽公共 `AsyncSlice` 工具（`src/stores/async.ts`），各 store 复用「api 调用 → `schema.safeParse` → adapter → 落 ViewModel」管线。
- 仅 `appStore` 用 `zustand/middleware` 的 `persist` 持久化 `projectId/scenarioId/runId`；domain 数据仍内存、按需重拉。
- 引入 **zustand 5.1.0**（不加 immer 等重库，手写不可变更新）。

## 改动点

- 新增 `src/stores/async.ts`：`AsyncStatus`/`AsyncSlice<T>` + `idleSlice/loadingSlice/successSlice/errorSlice`（loading/error 保留上次 data）+ `schemaValidationError`（422 `VALIDATION_FAILED`）+ `isStaleRun`（晚到守卫）+ `normalizeApiError`（避免二次包裹 `UNKNOWN_ERROR`）。
- 新增 `src/stores/appStore.ts`：`projectId/scenarioId/runId` + setter + `resetRunContext`；`persist` 仅 partialize 三者，`safeStorage` 在无 localStorage（node 测试/SSR）下降级不抛错。
- 新增 `src/stores/uiStore.ts`：`selectedNodeId/LinkId/FlowId`、`wsStatus`、`displayPrefs` + 选择/清除/连接态/偏好 action。
- 新增 `src/stores/simulationStore.ts`：`run`（`AsyncSlice<SimulationRun>`）+ `loadRun/loadStatus/createRun/start/pause/resume/stop/step/setSpeed` 异步 action + `resetRun` + `applyRealtimeEvent`（状态/时钟/完成/错误折算）；异步 action 统一 `commitRun`（校验+适配+runId 晚到守卫）。
- 新增 `src/stores/topologyStore.ts`：`snapshot`（`AsyncSlice<TopologySnapshot>`）+ `loadTopology` + `resetRun` + `applyRealtimeEvent`；纯函数 `applyTopologyEvent/updateNode/updateLink/updateFlow` 折算实时事件；`selectNodesById/selectLinksById/selectFlowsById` 用 selector 现算索引（不重复存）。
- 新增 `src/stores/scenarioStore.ts`：`list/current/validateResult`（三个 `AsyncSlice`）+ `pagination` + 本地 `draft` 编辑态；`listScenarios/loadScenario/createScenario/updateScenario/deleteScenario/validateScenario/cloneScenario` 异步 action + `setDraft/resetScenario`。
- 更新 `src/stores/index.ts`：由占位改为 barrel 导出上述 store 与公共工具。
- 新增 6 个测试文件：`async.test.ts`（9）/ `appStore.test.ts`（4，jsdom 覆盖 persist）/ `uiStore.test.ts`（4）/ `simulationStore.test.ts`（8，node+MSW）/ `topologyStore.test.ts`（16，node+MSW+纯函数）/ `scenarioStore.test.ts`（12，node+MSW）。

## 功能描述

建立按领域拆分的 Zustand Store 与 selector：页面共享同一份当前运行状态；异步请求区分 idle/loading/success/error；服务端事实态与本地编辑态分离；所有运行数据按 runId 隔离，晚到旧请求经 `isStaleRun` 丢弃，切换 run 后旧拓扑/仿真/消息不残留。Agent/Resource/Metric 域待二轮类型补齐。
