# FE-008 代码评审修复（P1 / P2）

- **日期**：2026-11-09
- **任务**：代码评审修复（P1 / P2，无对应里程碑编号）

## 修复点

- **P1 响应拦截器漏判业务 code**：`src/api/client.ts` 成功分支此前无条件解包 `data`，
  现对「HTTP 2xx 但信封 `code` 非 `OK`」的响应按业务错误拒绝；`src/api/errors.ts` 新增
  `ApiError.fromBusinessError`，保留 `requestId`/`details`/`fieldErrors`。
- **P1 Mock 事件边界遗漏**：`src/mocks/world.ts` 的到期过滤由 `triggerAtMs > from` 改为
  `triggerAtMs >= from`，使恰好落在当前仿真时刻（含 0）的事件也能触发。
- **P2 拓扑 selector 引用不稳定**：`src/stores/topologyStore.ts` 的
  `selectNodesById` / `selectLinksById` / `selectFlowsById` 改为按快照引用缓存的稳定引用，
  数据未变时返回同一 `Map`，避免 `useStore` 订阅时因新引用造成不必要重渲染。
- **P2 真实 WebSocket 空实现抛异常**：`src/api/realtime.ts` 的 `NativeRealtimeProvider`
  不再在 `subscribe` 中上抛异常，改为经 `RealtimeSubscriber.onError` / `onStatus('error')`
  上报并返回可 `close` 的空连接；`RealtimeSubscriber` 新增可选 `onError` 回调。
