仿真环境场景库

(sce20261031-conf01版)

本场景库依据赛题发布清单编制，共10个场景（sce01~sce10），从易到难排列；每场景10个场景脚本（script-01~script-10），场景内脚本同样从易到难。各场景的无人平台、地面节点、空中节点、链路、背景业务与测试业务流规模逐场景递增（逐场景数值见下表），节点总数50~300。业务QoS需求在配置区间内取样并量化到工程档位；每条业务初始选定的可行路径与各脚本全部事件生效后的末态选定路径在<场景标识>-stats.md的业务统计节逐业务列出，逐链路参数与端到端合成计算以LaTeX公式给出。

## 场景内容

每个场景目录（data/scenarios/<场景套件>/<场景标识>/）包含四类文件。net-topo.json是网络拓扑，给出场景区域范围、全部节点与链路及每条链路的参数，链路参数在conf/linkTypes.json定义的链路类型范围内取值并按工程精度取整；bg-service.json是初始业务需求，逐条给出业务类型、源宿节点、发送速率与时延、抖动、丢包率、误码率上限，category字段区分背景业务与测试业务流；script-01.json~script-10.json是场景脚本；<场景标识>-stats.md是场景统计文档，由export_scenario_stats.py从上述文件导出，分概览、节点统计、链路统计、业务统计四节，业务统计节逐业务列出初始与末态选定路径及其合成计算。

## 场景脚本与事件

场景脚本是一份事件列表，每项含发生时间（相对场景启动T0的秒数）、事件类型与属性。事件共六类：节点下线与节点上线使指定节点不可用或恢复在线；节点移动把节点从一处移至另一处，移动由仿真按3~6个插值点逐步执行，每到达一个插值点伴随一次链路事件；链路参数变化调整指定链路的带宽、时延、抖动、丢包率或误码率，取值在链路类型范围内；链路中断与链路恢复切断或接通指定链路；业务调整在场景运行中新增一条业务。每条脚本列表末尾另有生成器自动附加的 stop 事件（发生时间＝测试结束时刻），到点由仿真结束测试实例，无需智能体处理。

## 难度模型

难度系数d由场景序号与脚本序号线性决定：d＝((场景序号−1)×10＋脚本序号)/100，取值(0,1]，全库最后一个脚本难度最高。d越大，脚本越难：事件按簇产生于T0+3~26分钟窗口内（簇间隔3~5分钟、簇内间隔10~60秒），事件序列按需在窗内等比压缩散布、不堆叠于窗尾；每脚本事件簇数5~8个、每簇1~5条（并按d的概率追加一条）；事件类型构成随d演进（链路参数变化0.70→0.40、节点下线0.10→0.35、业务调整0.10→0.30、链路中断0.05→0.20、节点移动0.05→0.10）；链路参数劣化强度与d成正比（0.3+0.6×d）。

## 使用方法

在simulator/gen_scripts/下运行 python3 gen_scenarios.py --conf <配置集目录>（默认gen_conf01；配置集按gen_conf<两位序号>命名，一套一个params.yaml——只含场景规模与事件时间参数，生成逻辑默认参数在同目录gen_internal.yaml）。场景套件输出到simulator/data/scenarios/sce20261031-conf01/，启动仿真时指定场景套件标识（sce20261031-conf01）与场景标识（sce01~sce10）。链路类型定义在conf/linkTypes.json，全局所有场景共用；演示素材置于simulator/assets/{image,voice,video}/，bg-service.json经media.dir引用；运行日志按logs/<场景套件>/<场景标识>/<脚本名称>/<实例>/落盘，脚本名称为场景脚本文件的基本名（如script-01）。拓扑图与业务关系图（data/figures/<场景套件>/<场景>/）为派生物，由plot_topo.py与plot_services.py生成，与场景数据分目录存放。生成种子固定（SEED-＋场景标识/脚本序号），重复生成结果一致。
